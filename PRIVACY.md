# Privacy And Data Boundary

## Default State

Telemetry is disabled by default. The package does not install hooks, edit settings, start services, scan transcripts, upload files, or contact an external provider.

## Optional Usage Events

When a user separately enables the logger, each new event contains exactly:

- `ts`: UTC timestamp;
- `skill`: canonical Skill identifier;
- `session_id`: first 12 hexadecimal characters of a SHA-256 digest of the source session identifier.

The logger must not retain prompts, tool input, transcript text, file paths, file content, outputs, credentials, case data, or model logs. Aggregate reports omit session identifiers.

The digest is pseudonymous, not anonymous. Users remain responsible for access control, retention, and deletion of their local log.

## Candidate And Review Evidence

Candidate artifacts may contain material supplied by the user or generated by worker commands. Configure read roots, write roots, network policy, retention, and redaction before running live work. Do not publish candidate evidence merely because the release package itself passes privacy hygiene checks.

## External Services

The included code does not require an external provider. User-supplied agent or worker commands may have separate provider, credential, privacy, and billing behavior. Those behaviors are not controlled or guaranteed by this package.
