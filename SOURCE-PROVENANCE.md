# Source Provenance

This V4 package was built as a sanitized snapshot of the locally installed Skill Sublation runtime after its governed V3 and V4 candidate changes.

The public release baseline is the prior MIT-licensed V3 package. V4 adds the current formal runtime scripts plus the scenario-taxonomy, usage-telemetry, and value-delivery modules that passed local multi-seat candidate review and entered the formal observation window.

No third-party Skill source, private candidate payload, rollback copy, internal room log, user-specific path, credential, or case material is included. The package is distributed under the MIT License in `LICENSE`.
